# Datasheet curves

On-axis SPL curves (and the 30-degree curve of the midrange) extracted from the vector graphics
of the manufacturers' PDF datasheets, point by point, with the plot grids as calibration
(`freq_hz`, `spl_db`):

| file | source |
|---|---|
| `dayton_sig225_4_spl.csv` | Dayton Audio SIG225-4 specification sheet (2.83 V / 1 m) |
| `hivi_dm7600_spl_0deg.csv`, `hivi_dm7600_spl_30deg.csv` | HiVi (Swan) DM-7600 datasheet (2.83 V / 1 m) |
| `sica_lp9028_n92_spl.csv` | SICA LP 90.28/N92 TW 8 ohm, code Z009160 (IEC baffle, 1 W / 1 m) |

The data belong to their manufacturers and are used here for technical analysis only.
